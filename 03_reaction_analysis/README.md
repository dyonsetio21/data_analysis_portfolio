# Social Media Reaction Analysis

## Project Overview

This project analyzes user engagement on social media by exploring reaction data using Python. The objective is to identify engagement patterns, understand user behavior, and visualize reaction trends over time.

The project was completed as part of the **Accenture North America Data Analytics and Visualization Virtual Experience Program** on Forage.

---

## Business Problem

Social media platforms generate large volumes of user interactions every day. Understanding how users react to content helps businesses evaluate engagement levels and improve content strategies.

This project answers several business questions, including:

- Which reaction types are most common?
- How does user engagement change over time?
- At what time of day are users most active?
- What behavioral patterns can be identified from reaction data?

---

## Project Objectives

- Explore the distribution of user reactions
- Analyze engagement trends over time
- Identify peak engagement hours
- Visualize user interaction patterns
- Generate insights to support content strategy

---

## Dataset

Dataset provided through the **Accenture North America Data Analytics and Visualization Virtual Experience Program (Forage).**

The dataset contains information such as:

- Reaction Type
- Reaction Date
- Reaction Time
- User Engagement Records

# Key Findings

## 1. Distribution of Reaction Types

![result1](https://github.com/dyonsetio21/data_analysis_portfolio/blob/main/03_reaction_analysis/images/chart1.png)

### Insights

- User engagement was distributed across several reaction types, including Like, Love, Haha, Wow, Sad, and Angry.
- Certain reaction types appeared much more frequently, indicating stronger user preferences for positive interactions.

---

## 2. Daily Reaction Trends

![result2](https://github.com/dyonsetio21/data_analysis_portfolio/blob/main/03_reaction_analysis/images/chart2.png)

### Insights

- Daily engagement fluctuated over time rather than remaining constant.
- Several periods showed noticeable spikes in user activity, suggesting the influence of specific content or events.

---

## 3. Reaction Trends by Publication Hour

![result3](https://github.com/dyonsetio21/data_analysis_portfolio/blob/main/03_reaction_analysis/images/chart3.png)

### Insights

- User activity varied throughout the day.
- Certain hours consistently generated higher engagement than others, indicating optimal publishing times.

---

# Business Recommendations

Based on the analysis:

- Schedule content during peak engagement hours to maximize audience reach.
- Analyze high-performing content published on days with significant engagement spikes.
- Monitor reaction distribution to better understand audience sentiment.
- Continue tracking engagement trends to support future content planning.
